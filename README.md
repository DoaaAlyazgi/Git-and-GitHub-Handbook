# 📚 Git & GitHub Handbook

> A practical and beginner-friendly handbook for learning Git and GitHub step by step.

---

## 🌐 English

### 📖 About This Handbook

**Git & GitHub Handbook** is a practical reference designed to help beginners understand Git and GitHub from the basics to more advanced workflows.

The handbook explains Git commands, branching, merging, remote repositories, GitHub collaboration, and common errors through simple explanations and practical examples.

Whether you are just starting with Git or want a quick reference for common commands, this handbook is designed to make Git easier to understand and use.

---

## 🎯 What You'll Learn

By completing this handbook, you will learn how to:

- Understand Git and version control
- Understand the difference between Git and GitHub
- Install and configure Git
- Create and manage Git repositories
- Track and commit changes
- Work with branches
- Merge branches
- Temporarily save changes using Stash
- Apply specific commits using Cherry-Pick
- Rewrite history using Rebase
- Work with GitHub repositories
- Push and pull changes
- Clone repositories
- Fork repositories
- Create Pull Requests
- Understand and solve common Git errors

## 💻 Basic Git Workflow

A common Git workflow looks like this:

```bash
git init
git status
git add .
git commit -m "Initial commit"
git branch
git switch -c feature
git add .
git commit -m "Add feature"
git switch main
git merge feature
```

When working with GitHub:

```bash
git remote add origin repository-url
git push -u origin main
git pull origin main
```

## 🧠 Quick Reference

Some of the most commonly used commands:

| Command | Description |
|---|---|
| `git init` | Initialize a Git repository |
| `git status` | Check repository status |
| `git add` | Stage changes |
| `git commit` | Save changes to Git history |
| `git log` | View commit history |
| `git branch` | Manage branches |
| `git switch` | Switch branches |
| `git merge` | Merge branches |
| `git stash` | Temporarily save changes |
| `git cherry-pick` | Apply a specific commit |
| `git rebase` | Reapply commits onto another base |
| `git clone` | Copy a remote repository |
| `git push` | Upload commits |
| `git pull` | Download and integrate changes |

## 💡 Tips for Learning Git

- Practice commands instead of only reading them.
- Create small test repositories.
- Experiment with branches.
- Learn from Git error messages.
- Use `git status` frequently.
- Check your commit history with `git log`.
- Never run destructive commands without understanding them.
