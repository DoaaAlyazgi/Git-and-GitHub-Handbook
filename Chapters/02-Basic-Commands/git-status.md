# ➕ Git Add

## 🌐 English

`git add` is used to add changes to the Git staging area.

The staging area allows you to choose which changes should be included in the next commit.

### 🔹 Basic Usage

To add a specific file to the staging area:

```bash
git add filename.txt
```

---

## 🇵🇸 العربية

يُستخدم الأمر `git add` لإضافة التغييرات إلى منطقة التجهيز (Staging Area) في Git.

تسمح لك منطقة التجهيز باختيار التغييرات التي تريد تضمينها في عملية Commit القادمة.

### 🔹 الاستخدام الأساسي

لإضافة ملف محدد إلى منطقة التجهيز:

```bash
git add filename.txt
```
