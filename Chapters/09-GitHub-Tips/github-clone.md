# 📥 Git Clone

## 🌐 English

`git clone` is used to create a local copy of an existing Git repository.

It is commonly used to download a repository from GitHub to your computer.

---

## 🔹 Basic Usage

```bash
git clone repository-url
```

Example:

```bash
git clone https://github.com/username/project.git
```

Git creates a local directory containing the repository.

---

## 🔹 Clone into a Specific Folder

You can specify the folder name:

```bash
git clone repository-url my-project
```

---

## 🔹 Enter the Repository

After cloning:

```bash
cd project
```

Then check the status:

```bash
git status
```

---

## 🔹 View the Remote

A cloned repository automatically has a remote configured.

You can check it with:

```bash
git remote -v
```

---

## 💡 When to Use Git Clone

Use `git clone` when:

- You want to download an existing project
- You want to contribute to a GitHub project
- You are setting up a project on a new computer
- You need a local copy of a repository

---

## 📝 Summary

```bash
git clone repository-url
```

Git Clone creates a local copy of an existing repository.

# 🇵🇸 العربية

# 📥 Git Clone

## العربية

يُستخدم `git clone` لإنشاء نسخة محلية من مستودع Git موجود.

يُستخدم عادةً لتنزيل مستودع من GitHub إلى جهاز الكمبيوتر الخاص بك.

---

## 🔹 الاستخدام الأساسي

```bash
git clone repository-url
```

مثال:

```bash
git clone https://github.com/username/project.git
```

يقوم Git بإنشاء مجلد محلي يحتوي على المستودع.

---

## 🔹 النسخ إلى مجلد محدد

يمكنك تحديد اسم المجلد:

```bash
git clone repository-url my-project
```

---

## 🔹 الدخول إلى المستودع

بعد عملية Clone:

```bash
cd project
```

ثم تحقق من الحالة:

```bash
git status
```

---

## 🔹 عرض الـ Remote

يتم إعداد Remote تلقائيًا عند عمل Clone للمستودع.

يمكنك التحقق منه باستخدام:

```bash
git remote -v
```

---

## 💡 متى نستخدم Git Clone؟

استخدم `git clone` عندما:

- تريد تنزيل مشروع موجود
- تريد المساهمة في مشروع على GitHub
- تقوم بإعداد المشروع على جهاز جديد
- تحتاج إلى نسخة محلية من مستودع

---

## 📝 الخلاصة

```bash
git clone repository-url
```

يقوم Git Clone بإنشاء نسخة محلية من مستودع موجود.
