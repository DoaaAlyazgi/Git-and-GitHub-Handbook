# 📦 GitHub Repository

## 🌐 English

A GitHub repository is a place where a project is stored and managed on GitHub.

A repository can contain source code, files, folders, commits, branches, issues, Pull Requests, and other project information.

---

## 🔹 Creating a Repository

You can create a new repository from your GitHub account.

When creating a repository, you can provide:

- Repository name
- Description
- Visibility
- README file
- `.gitignore`
- License

---

## 🔹 Public vs Private Repository

A public repository can be viewed by anyone.

A private repository is only accessible to users who have been given permission.

---

## 🔹 Repository URL

Every GitHub repository has a URL.

For example:

```text
https://github.com/username/project-name
```

You can use this URL to access the repository or clone it.

---

## 🔹 Repository Contents

A repository can contain:

```text
Files
Folders
Branches
Commits
Issues
Pull Requests
Actions
Releases
```

---

## 💡 Why Use GitHub Repositories?

Repositories are useful for:

- Storing projects
- Tracking changes
- Collaborating with developers
- Sharing code
- Managing project versions

---

## 📝 Summary

A GitHub repository is the central place where a project and its Git history can be stored and managed online.

# 🇵🇸 العربية

# 📦 GitHub Repository

## العربية

مستودع GitHub هو المكان الذي يتم فيه تخزين وإدارة المشروع على GitHub.

يمكن أن يحتوي المستودع على الكود المصدري والملفات والمجلدات والـ Commits والفروع وIssues وPull Requests وغيرها من معلومات المشروع.

---

## 🔹 إنشاء مستودع

يمكنك إنشاء مستودع جديد من حسابك على GitHub.

عند إنشاء المستودع، يمكنك تحديد:

- اسم المستودع
- وصف المستودع
- مستوى الخصوصية
- ملف README
- ملف `.gitignore`
- الترخيص

---

## 🔹 المستودع العام مقابل الخاص

يمكن لأي شخص مشاهدة المستودع العام.

أما المستودع الخاص فلا يمكن الوصول إليه إلا من قبل المستخدمين الذين تم منحهم صلاحية الوصول.

---

## 🔹 رابط المستودع

لكل مستودع على GitHub رابط خاص به.

مثال:

```text
https://github.com/username/project-name
```

يمكن استخدام هذا الرابط للوصول إلى المستودع أو نسخه باستخدام Clone.

## 💡 لماذا نستخدم مستودعات GitHub؟
