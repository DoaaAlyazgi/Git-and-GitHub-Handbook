# 🍴 GitHub Fork

## 🌐 English

A Fork is a copy of another user's repository under your own GitHub account.

Forks are commonly used when you want to contribute to a repository without having direct write access to it.

---

## 🔹 Create a Fork

On GitHub, open the repository you want to copy.

Select:

```text
Fork
```

GitHub creates a copy of the repository under your account.

---

## 🔹 Clone Your Fork

After creating the fork, clone it:

```bash
git clone repository-url
```

Then enter the project:

```bash
cd project
```

---

## 🔹 Create a Feature Branch

Create a new branch:

```bash
git switch -c feature-branch
```

Make your changes and commit them:

```bash
git add .
git commit -m "Add new feature"
```

---

## 🔹 Push Your Branch

```bash
git push -u origin feature-branch
```

---

## 🔹 Create a Pull Request

After pushing your branch, you can create a Pull Request from your fork to the original repository.

---

## 💡 Why Use Forks?

Forks are useful when:

- You do not have write access to a repository
- You want to contribute to an open-source project
- You want your own copy of a repository
- You want to experiment without affecting the original repository

---

## 📝 Summary

A Fork creates your own GitHub copy of another repository.

A common workflow is:

```text
Fork
 ↓
Clone
 ↓
Create Branch
 ↓
Make Changes
 ↓
Commit
 ↓
Push
 ↓
Pull Request
```

# 🇵🇸 العربية

# 🍴 GitHub Fork

## العربية

الـ Fork هو نسخة من مستودع مستخدم آخر يتم إنشاؤها تحت حساب GitHub الخاص بك.

يُستخدم Fork عادةً عندما تريد المساهمة في مستودع لا تملك صلاحية الكتابة المباشرة عليه.

---

## 🔹 إنشاء Fork

على GitHub، افتح المستودع الذي تريد نسخه.

اختر:

```text
Fork
```

يقوم GitHub بإنشاء نسخة من المستودع تحت حسابك.

---

## 🔹 نسخ Fork إلى جهازك

بعد إنشاء Fork، قم بعمل Clone:

```bash
git clone repository-url
```

ثم ادخل إلى المشروع:

```bash
cd project
```

---

## 🔹 إنشاء Feature Branch

أنشئ فرعًا جديدًا:

```bash
git switch -c feature-branch
```

قم بإجراء التغييرات ثم أنشئ Commit:

```bash
git add .
git commit -m "Add new feature"
```

---

## 🔹 رفع الفرع

```bash
git push -u origin feature-branch
```

---

## 🔹 إنشاء Pull Request

بعد رفع الفرع، يمكنك إنشاء Pull Request من الـ Fork الخاص بك إلى المستودع الأصلي.

---

## 💡 لماذا نستخدم Fork؟

يكون Fork مفيدًا عندما:

- لا تملك صلاحية الكتابة على المستودع
- تريد المساهمة في مشروع Open Source
- تريد نسخة خاصة بك من المستودع
- تريد تجربة تغييرات دون التأثير على المستودع الأصلي

---

## 📝 الخلاصة

يقوم Fork بإنشاء نسخة خاصة بك على GitHub من مستودع آخر.

سير العمل المعتاد:

```text
Fork
 ↓
Clone
 ↓
Create Branch
 ↓
Make Changes
 ↓
Commit
 ↓
Push
 ↓
Pull Request
```
