# 📌 What is Git?

## 🌐 English

Git is a distributed Version Control System (VCS) that helps developers track changes in their projects.

It allows you to:

- Save different versions of your code.
- See what has changed over time.
- Go back to previous versions when needed.
- Work on different features without affecting the main project.
- Collaborate with other developers.

### 💡 Think of Git as a Time Machine for Your Code

Imagine you are working on a project and make several changes.

Later, you discover that something is broken.

Without Git, finding and restoring the previous working version can be difficult.

With Git, you can keep a history of your changes and return to an earlier version when necessary.

---

## 🌐 العربية

Git هو نظام للتحكم في إصدارات المشاريع (Version Control System)، يساعد المطورين على تتبع التغييرات التي يقومون بها على مشاريعهم.

يسمح لك Git بأن:

- تحفظ إصدارات مختلفة من مشروعك.
- تعرف ما الذي تغير في المشروع مع مرور الوقت.
- تعود إلى إصدارات سابقة عند الحاجة.
- تعمل على ميزات مختلفة دون التأثير على المشروع الرئيسي.
- تتعاون مع مطورين آخرين.

### 💡 تخيّل Git كأنه آلة زمن للكود

تخيّل أنك تعمل على مشروع وأجريت عليه العديد من التعديلات.

بعد فترة اكتشفت أن أحد التعديلات تسبب في مشكلة.

بدون Git، قد يكون من الصعب معرفة أين حدث الخطأ والعودة إلى النسخة التي كانت تعمل بشكل صحيح.

أما باستخدام Git، فيتم الاحتفاظ بتاريخ التغييرات، ويمكنك الرجوع إلى إصدار سابق من المشروع عند الحاجة.

---

## 🧠 Key Idea

> Git tracks the history of your project so you can manage, understand, and safely change your code.

> Git يتتبع تاريخ مشروعك، مما يساعدك على إدارة الكود وفهم التغييرات وإجرائها بأمان.

---

## ✅ Summary

Git is a tool that helps developers manage and track changes in their projects.

It is one of the most important tools for modern software development and is the foundation for many workflows involving GitHub.
