# 📌 What is GitHub?

## 🌐 English

GitHub is a cloud-based platform that allows developers to store, manage, share, and collaborate on software projects using Git.

While Git runs on your computer and tracks changes in your project, GitHub provides an online place where Git repositories can be stored and shared.

### 💡 Think of GitHub as a Home for Your Git Repositories

Imagine that Git is responsible for tracking the history of your project on your computer.

GitHub gives that project a place on the internet where you can:

- Store your Git repositories online.
- Back up your projects.
- Share your code with others.
- Collaborate with other developers.
- Work on projects from different computers.
- Review and discuss code changes.
- Contribute to open-source projects.

---

## 🔄 Git vs GitHub

It is important to understand that **Git and GitHub are not the same thing**.

### Git

Git is a **Version Control System (VCS)**.

It runs on your computer and helps you:

- Track changes.
- Create commits.
- Create branches.
- Switch between versions.
- Merge changes.
- Restore previous versions.

### GitHub

GitHub is an **online platform** built around Git.

It helps you:

- Store repositories online.
- Share projects.
- Collaborate with developers.
- Manage issues and pull requests.
- Review code.
- Contribute to open-source projects.

### 🧠 Simple Example

Think about it this way:

> **Git = The tool that manages your project's history.**

> **GitHub = The platform where you can store and collaborate on that project online.**

You can use Git without GitHub.

For example, you can create a Git repository on your computer and use Git to track all your changes without uploading the project anywhere.

However, GitHub makes it easier to share your repository and collaborate with other developers.

---

## 📦 What is a GitHub Repository?

A **repository (repo)** is a project stored on GitHub.

A repository can contain:

- Source code.
- Documentation.
- Images.
- Configuration files.
- README files.
- Git history.
- Branches.
- Issues.
- Pull requests.

For example, this handbook itself is stored inside a GitHub repository.

The repository can be used to organize the entire project and keep its development history.

---

## 👥 Collaboration on GitHub

One of GitHub's biggest advantages is collaboration.

Multiple developers can work on the same project without constantly sending files to each other.

For example:

1. Developer A creates a feature.
2. Developer A creates a branch.
3. Developer A makes changes and commits them.
4. Developer A pushes the branch to GitHub.
5. Developer A creates a Pull Request.
6. Other developers review the changes.
7. The team discusses and improves the code.
8. The changes are merged into the main branch.

This workflow is commonly used in professional software development.

---

## 🌍 Open Source

GitHub is also one of the largest platforms for open-source software.

Open-source projects allow developers to view, use, and sometimes contribute to the source code.

Developers can:

- Discover useful projects.
- Learn from real-world code.
- Report bugs.
- Suggest improvements.
- Submit Pull Requests.
- Contribute to projects created by other developers.

This makes GitHub an important platform for learning and professional development.

## 🧩 GitHub Features You Should Know

Here are some important GitHub features:

| Feature | Purpose |
|---|---|
| Repository | Stores a project and its Git history |
| Branch | Allows development without changing another branch |
| Commit | Saves a set of changes |
| Pull Request | Proposes changes for review and merging |
| Issue | Tracks bugs, tasks, and ideas |
| Actions | Automates workflows |
| Releases | Publishes versions of a project |
| README | Explains what a project is and how to use it |

You will learn these features step by step throughout this handbook.

## 🎯 Why Should Developers Learn GitHub?

Learning GitHub is useful because it helps developers work professionally.

It allows you to:

- Build a public portfolio.
- Share your projects.
- Collaborate with teams.
- Contribute to open-source projects.
- Learn from other developers.
- Track your project's history.
- Work with modern development workflows.

A well-organized GitHub profile can also help demonstrate your technical skills to potential employers or clients.

---

## 📝 Quick Summary

Git and GitHub work together, but they have different roles.

**Git** is the version control tool that tracks changes locally.

**GitHub** is the online platform that stores Git repositories and provides collaboration features.

A simple way to remember the difference is:

> **Git manages your code history.**

> **GitHub helps you store, share, and collaborate on that code online.**

## 🇵🇸 العربية

GitHub هو **منصة تعمل عبر الإنترنت** وتسمح للمطورين بتخزين وإدارة ومشاركة والتعاون على مشاريع البرمجيات باستخدام Git.

بينما يعمل Git على جهازك ويتولى تتبع التغييرات التي تحدث في مشروعك، يوفر GitHub مكانًا على الإنترنت يمكن فيه تخزين مستودعات Git ومشاركتها.

### 💡 تخيل GitHub كأنه منزل لمستودعات Git الخاصة بك

تخيل أن Git مسؤول عن تتبع تاريخ مشروعك على جهاز الكمبيوتر الخاص بك.

أما GitHub فيوفر لهذا المشروع مكانًا على الإنترنت يمكنك من خلاله:

- تخزين مستودعات Git الخاصة بك.
- الاحتفاظ بنسخة احتياطية من مشاريعك.
- مشاركة الكود مع الآخرين.
- التعاون مع مطورين آخرين.
- العمل على المشاريع من أجهزة كمبيوتر مختلفة.
- مراجعة ومناقشة تغييرات الكود.
- المساهمة في مشاريع مفتوحة المصدر.

## 🔄 Git مقابل GitHub

من المهم جدًا أن تفهم أن **Git وGitHub ليسا الشيء نفسه**.

### Git

Git هو **نظام للتحكم في الإصدارات (Version Control System - VCS)**.

يعمل على جهاز الكمبيوتر الخاص بك ويساعدك على:

- تتبع التغييرات.
- إنشاء Commits.
- إنشاء Branches.
- الانتقال بين الإصدارات.
- دمج التغييرات.
- استعادة الإصدارات السابقة.

### GitHub

GitHub هو **منصة على الإنترنت مبنية حول Git**.

يساعدك على:

- تخزين المستودعات على الإنترنت.
- مشاركة المشاريع.
- التعاون مع المطورين.
- إدارة Issues وPull Requests.
- مراجعة الكود.
- المساهمة في مشاريع مفتوحة المصدر.

### 🧠 مثال بسيط

فكر فيها بهذه الطريقة:

> **Git = الأداة التي تدير تاريخ مشروعك.**

> **GitHub = المنصة التي تتيح لك تخزين هذا المشروع والتعاون عليه عبر الإنترنت.**

يمكنك استخدام Git بدون GitHub.

على سبيل المثال، يمكنك إنشاء Git Repository على جهاز الكمبيوتر الخاص بك واستخدام Git لتتبع جميع التغييرات التي تحدث في المشروع دون رفعه إلى أي مكان.

لكن GitHub يجعل مشاركة المستودع والتعاون مع المطورين الآخرين أسهل بكثير.

يمكن أن يحتوي المستودع على:

- Source Code.
- Documentation.
- Images.
- Configuration Files.
- README Files.
- Git History.
- Branches.
- Issues.
- Pull Requests.

على سبيل المثال، هذا الـ Handbook نفسه موجود داخل GitHub Repository.

ويمكن استخدام المستودع لتنظيم المشروع بالكامل والاحتفاظ بتاريخ تطويره.

---

## 👥 التعاون باستخدام GitHub

واحدة من أكبر مميزات GitHub هي **التعاون**.

يمكن لعدة مطورين العمل على المشروع نفسه دون الحاجة إلى إرسال الملفات لبعضهم البعض بشكل مستمر.

على سبيل المثال:

1. يقوم المطور الأول بإنشاء Feature جديدة.
2. يقوم بإنشاء Branch.
3. يجري التغييرات ثم ينشئ Commit.
4. يرفع الـ Branch إلى GitHub.
5. ينشئ Pull Request.
6. يقوم مطورون آخرون بمراجعة التغييرات.
7. يناقش الفريق الكود ويحسّنه.
8. يتم دمج التغييرات داخل الـ Main Branch.

هذا النوع من الـ Workflow يُستخدم بشكل واسع في تطوير البرمجيات الاحترافي.

---

## 🌍 المشاريع مفتوحة المصدر

يُعتبر GitHub أيضًا واحدًا من أكبر المنصات للمشاريع مفتوحة المصدر.

المشاريع مفتوحة المصدر تسمح للمطورين بالاطلاع على الكود واستخدامه، وفي بعض الحالات المساهمة في تطويره.

يمكن للمطورين:

- اكتشاف مشاريع مفيدة.
- التعلم من كود حقيقي.
- الإبلاغ عن الأخطاء.
- اقتراح التحسينات.
- إرسال Pull Requests.
- المساهمة في مشاريع أنشأها مطورون آخرون.

وهذا يجعل GitHub منصة مهمة جدًا للتعلم والتطور المهني.

## 📝 الخلاصة السريعة

يعمل Git وGitHub معًا، لكن لكل واحد منهما وظيفة مختلفة.

**Git** هو أداة التحكم بالإصدارات التي تتتبع التغييرات على جهازك.

**GitHub** هو المنصة الموجودة على الإنترنت التي تستضيف مستودعات Git وتوفر أدوات التعاون والعمل الجماعي.

طريقة بسيطة لتذكر الفرق:

> **Git يدير تاريخ الكود الخاص بك.**

> **GitHub يساعدك على تخزين ومشاركة والتعاون على هذا الكود عبر الإنترنت.**
